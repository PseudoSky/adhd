## File interface specs
Root: `packages/policy/policy-core-client/src/core/`. Same import rules as T03. `evaluate`/`explain` are total: they catch internally and return a deny with `eval-error`, including when a permission's `context`/`args` cannot be evaluated (the reason names the permission id, C2). `resolve` throws `PolicyEvalError` (naming the defaults rule) when a `where` cannot be evaluated; the service maps it to `ApiError('internal')`, and `evaluate`/`explain` turn it into deny `eval-error`.

import type { AttributeKind, AttributeValue } from '../../spec/index.js';
/** Union per MG-04: names/paths -> set union preserving first-seen order, deduped; number -> the larger value; name -> the second argument replaces. */

### `core/attributes/resolve.ts`
```ts
import type { Attributes, ICompiledPolicy, IResolved } from '../../spec/index.js';
/** Applies `policy.defaults` to the supplied attributes. Supplied values are final (AT-04). Attributes not declared in `policy.attributes` are dropped from the result (AT-11). */

```
### `core/attributes/narrow.ts`
```ts
import type { Attributes, ICompiledPolicy, INarrowRequest, INarrowResult } from '../../spec/index.js';
/** Algorithm (all steps pure; parent never mutated; keys processed in ascending key order so the FIRST failure is deterministic):
 *  1. S = resolveAttributes(policy, request.attributes).attributes   // child-specified, supplied are final
 *  2. Every key of `grant` and `only` must be declared in policy.attributes AND be in the union of `narrowingCovered` values (NR-04), else fail {variable:key, rule:'uncovered'}. A key present in request.attributes cannot be granted/only'd: fail rule 'supplied-final'. Type of a value must match its kind else rule 'type'.
 *  3. add step per key: in S and grant -> unionValues(kind,S,grant); only S -> S; only grant -> grant; neither -> parent value (MG-01..04). Keys the parent and S/grant lack are absent.
 *  4. `only[key]` must satisfy isWithin(kind, only, add) else fail rule 'only-outside' (MG-07); on success it REPLACES the add result (MG-05). grant is applied before only (MG-06).
 *  5. For every completed key that is NOT supplied: if the parent has the key, isWithin(kind, child, parent) else fail rule 'exceeds-parent' (MG-08/09, no clamping); if the parent lacks it -> 'exceeds-parent'.
 *  Result: { ok:true, child } where child = all completed keys (supplied ones included), declaration order irrelevant (object key order = ascending). Failure: { ok:false, variable, rule, reason } with reason = a one-sentence human string that names the variable. */
export function narrowAttributes(policy: ICompiledPolicy, parent: Attributes, request: INarrowRequest): INarrowResult;
```

### `core/evaluate/evaluate.ts`
```ts
import type { Attributes, ICompiledPolicy, IDecision, IExplanation, IRuntimeValues, IToolCall } from '../../spec/index.js';
/** Shared engine for evaluate and explain. Procedure (spec §4.3 + D-02/D-13):
 *  1 select by tool; 2 attrs = resolveAttributes; for any selected permission with readsRuntime and runtime === undefined -> deny 'runtime-unavailable' (RT-09);
 *  3 contextRow = {...attrs, runtime}; permission applicable iff context undefined or matchesPresent(contextRow, context) — AT-10/AT-12: before the engine runs, every field comparison whose field path is absent from the row (own key or dotted path; `undefined` counts as absent) is replaced by the constant-false node `{ '$$never': { _eq: 1 } }`, so `_ne`, `_nin`, `_nlike` and `_is_null: true` cannot be true on a missing attribute, EXCEPT a field whose operator set is exactly `_is_null` (the presence test: true for an absent field when `true`, false when `false`). `_not` over such a comparison negates the false comparison. `args` rows keep plain `matches` (engine semantics);
 *  4 for applicable: args' = substitute(args, attrs); argsMatched = args undefined or matches(callArgsRow, args');
 *  5 matched = ids of permissions where both pass, in order; deny wins, else ask, else allow, else deny 'no-match';
 *  6 set = merge of `set` from matching allow/ask permissions; two permissions forcing different values for one key -> deny 'eval-error' (reason names the key);
 *  7 any exception -> deny 'eval-error' (FC-01). `set` is {} on deny. Never reads the clock, env or fs. */
export function evaluateDetailed(policy: ICompiledPolicy, call: IToolCall, attributes?: Attributes, runtime?: IRuntimeValues): IExplanation;
export function evaluate(policy: ICompiledPolicy, call: IToolCall, attributes?: Attributes, runtime?: IRuntimeValues): IDecision;   // = evaluateDetailed(...).decision
```

- Security fix (post-T04): `context` evaluation uses `matchesPresent`; verified with a throwaway driver (`{role:{_ne:'guest'}}` with no `role` -> false; `_nin`, `_nlike` false; `_is_null:true` true / `false` false on absent; present `_eq`/`_ne` unchanged; dotted `runtime.*` paths; `_and`/`_or` mixes).
