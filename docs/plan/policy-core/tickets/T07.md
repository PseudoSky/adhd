## File interface specs
Package `packages/apigen/apigen-plugin-policy`. Imports ONLY `@adhd/apigen-engine-runtime` (types `Layer`, `Call`, `UsePlugin`, `Next`), `@adhd/apigen-base-errors` (`ApiError`), `node:path`/`node:url` in `load-decider.ts` only. NEVER any policy package. Verified (LI-01 closed): `--use` options (`useOptions[pluginId]`) are handed ONLY to a plugin's `mount.operations(descriptor, opts)` capability (`apigen-plugin-cli-output/src/lib/run.ts:586`, same in mcp/fastify/express), never to `layer`. Therefore the default export captures its options in a mount capability that returns `[]` (D-14). Attributes: Layer reads `call.envelope['attributes']` (D-18) — an earlier layer (auth) writes that key; the Layer declares no way for a caller to set it.

### `src/plugin.ts`
```ts
import type { UsePlugin } from '@adhd/apigen-engine-runtime';
import type { IPolicyAskHandler, IPolicyDecider } from './ports.js';
export interface IPolicyLayerOptions { readonly decider: IPolicyDecider | string; readonly deciderOptions?: Readonly<Record<string, unknown>>; readonly ask?: IPolicyAskHandler; readonly timeoutMs?: number }
/** Layer algorithm (LP-06..LP-17), one call: 1 resolve decider once (memoised promise; a load failure memoises a rejected state => every call denies); 2 map call.transport — 'http'|'grpc'|'mcp'|'cli' pass through; any other value => deny 'unsupported transport'; 3 request = {tool: call.operation.id, args: call.domainArgs, envelope: call.envelope, transport, attributes: validated call.envelope.attributes (only string|number|string[] values; invalid shape => undefined)}; 4 decision = await decide(request, call.signal) raced against timeoutMs (expiry => deny); 5 validate result shape (decision in allow|ask|deny; set is a plain object when present) else deny; 6 allow => Object.assign(call.domainArgs, set) then next(); 7 ask => ask handler 'allow-once' => next(), anything else/absent/throws => deny; 8 deny => throw new ApiError('permission_denied', reason ?? 'denied by policy', {code:'policy-denied'}). Holds no state between calls (LP-13). Streaming results are returned untouched (LP-12). */
export function createPolicyLayerPlugin(options: IPolicyLayerOptions): UsePlugin;
/** Default export loaded by `--use @adhd/apigen-plugin-policy`: id 'policy', capabilities.layer delegates to a plugin built from the captured options (throws ApiError('internal', 'apigen-plugin-policy: no decider configured') => treated as deny if options never arrived), capabilities.mount.operations(descriptor, opts) stores `opts` via state.set and returns []. */
declare const plugin: UsePlugin;
export default plugin;
```
