# T19 — tests: safety-relevant behaviors outside the demo

Phase: C · Depends on: Phase B · Agent: performance · Contract: ../INTERFACES.md D-06, D-08, D-15

## Scope
Three small functional tests the demo lacks but whose failure would silently widen access. Kept to the minimum; everything else the product agent listed as unproven stays build-gate-only.

## Acceptance (Gherkin)
Feature: Safety-relevant failure paths
  @S8.1 @negative
  Scenario: A decider that fails never allows
    Given the Layer is loaded with a decider that throws, one that never answers within the timeout, and one that returns a malformed result
    When a call is made through the apigen host
    Then every call is refused with permission_denied and the operation never runs
  @S8.2 @negative
  Scenario: serve refuses an upstream that is not an MCP server
    Given a bin source whose process does not answer the MCP initialize handshake
    When the user runs serve on it
    Then it fails with an error and does not fall back to treating it as a plain command   # D-08
  @S8.3 @edge
  Scenario: Attribute sources do not merge
    Given ADHD_POLICY_ATTRIBUTES sets role=intern and --adhd-attributes sets role=developer
    When a call is gated
    Then the decision uses role=developer only and nothing from the environment value   # D-06

Conventions for all test files: vitest, unit lane (`*.spec.ts`, no subprocess, no network, no sleeps), one `describe` per Gherkin Feature, test titles begin with the scenario tag (e.g. `@S2.3 ...`). Tests import ONLY what a third party can import: the package root (`@adhd/policy-core-client`), the CLI via `runPolicyCli` from `entrypoint/policy/src/wrapper/mount.ts` with `process.exitCode`/stdout captured by `helpers/capture.ts`, the Layer via its default export. Scratch files only under `tmp/policy/<test-name>/` created in `beforeEach`, removed in `afterEach`/`finally`. Negative controls are recorded in Evidence (not committed).
