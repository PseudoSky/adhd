## 6. Backlog tool facts (verified this session — each cost real time)

- **`backlog` and `adhd-backlog` are BOTH the v1 surface.** There is no `admin` verb, so the skill's mandatory `migration_status` pre-flight is **unavailable** on this install. `search` / `query` work.
- **`create` takes a FLAT input**: `{title, body, project, component, kind, priority, citations, by}`. The v2 `{item:{…}, by}` nesting is **rejected** with `invalid_argument`.
- **Body edits are copy-on-write and mint a NEW uid.** After any body `update`, re-read the returned uid and `relate` to **that** one — a stale uid returns `conflict: was superseded by a body edit and is no longer the live issue`.
- **The citation gate hard-fails on unverifiable paths** when the project has a path. `/tmp/...` (outside the repo) and worktree-only files cited repo-relative are both rejected: `precondition_failed: Citation target "…" could not be verified and this project requires a real sha`. Cite on-disk repo-relative paths — worktree files as `.worktrees/<wt>/...` — and **describe `ps`/`ls`/`vm_stat` evidence inline in the body rather than citing it**.
- `get` supports `fields:[…]` but **not** `includeDeleted`, and rejects `supersedes` / `supersededBy` as field names.
