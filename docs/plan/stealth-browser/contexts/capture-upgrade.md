## Goal

ONE capture pipeline: a `NetworkRecorder` folds `Network.*` events from an existing `CdpSession` into `RecordedExchange` records (request headers and postData, real status and response headers, ExtraInfo merged with extra-wins and the ordering hazard fixed, redirect chain, timing, failures kept), `captureNetworkResponse` becomes a thin wrapper over it, the inline WebSocket and the 500 ms debounce bug disappear, and an optional `RecordingSink` persists sessions: a `MemoryRecordingSink`, a `StoreRecordingSink` over `@adhd/sox-store-adapter` and `openStoreRecordingSink({ dbPath })` as the default concrete adapter. Status ban rules finally work because capture sees the real status. Built now by user decision.
