## Goal

The Chrome lifecycle ('v3', backlog 19dfb641) built once, by user decision (greenfield, no interim code, no later rewrite), on top of every feature and failsafe of the existing implementation (F1-F26 of EVAL-service-proxy.md): race-free launch, an idle reaper whose scope equals the source's, orphan reaping after `kill -9` through an out-of-process reaper host that counts live connections, a file-backed circuit breaker, exit-path shutdown and the isolated-context leak fixed at its source. Presence is one held connection per client (`dialBackend` to the reaper host of `@adhd/sox-service-proxy` 0.6.0); there is no presence registry, no lease and no heartbeat file. The policy engine (`decideReap` and the tiers) is in-package; one port, `ReaperLink`, is the only seam. Nothing the source does is removed.
