## Findings

1. **Point-in-time guards.** Completed-state guards compared trees to HEAD. After audit-fixes and resolve-findings changed code they went red (audit-pre-review.2/.4, audit-migration-blind.4, review-prep.4). Fixed by evaluating each completed state at its own `completion_ref` (`tree_sha_at`, `tw_tree_sha_at`). Commit tag `[plan-amend:frozen-trees]`.
2. **resolve-findings regressions found only by the full sweep.** The implementer's package gates were green, yet the 74-state sweep found: two specs without the ticket and criterion citation (search-hosts.16); a spec that lost the testing-standard header (conform-core.4/.5); the real-directory `mkdtemp` run of the storage contract removed to satisfy F61 (tripwire-core.31). The last was restored as `test/e2e/storage-contract.e2e.ts` (real-disk lane, `nx run resilience-core-tripwire:e2e`, exit 0), sharing cases through `test/helpers/storage-contract.ts`. Lesson: gate a remediation state on the sweep, not on the package gates alone.
3. **Deliberate behaviour change under two failsafes.** `cdpCall` returned `null` on failure (fs-177) and `BrowserService.getVersion` returned `null` when unreachable (fs-180). The resolved findings make both fail typed (CDP_UNREACHABLE, CDP_TIMEOUT, CDP_BAD_RESPONSE, CDP_REMOTE_ERROR). The failure is still contained and the 10 s timeout is kept; the failsafe inventory rows and pins were updated to the new tests `[plan-amend:failsafe-pins]`. This is the one place a documented behaviour changed rather than a feature removed.
4. **Stale evidence.** `evidence/tracing-log-validation.json` records `search_code_tree`; it went stale when search code changed and was refreshed inside resolve-findings (ownership amended).
5. **Dist manifest churn.** `nx run <p>:build` overwrites `dist/package.json` with the raw source manifest (paths `./dist/...`, `files: ["dist"]`); packing from `dist/` then lists three files. The publish chain regenerates the dist-relative manifest with `dist-manifest`. audit-final.9 now runs `dist-manifest` before `npm pack --dry-run`. Latent: `tarball_missing` never collects main/types because `collect()` is handed a list (only bin targets are checked). Not changed.
6. **Final-audit phase.** `run-audit.js --phase release` accumulates every criterion of its phase, including merge-readiness, consumer-relink and tripwire-reverse-relink, which depend on audit-final. Those 16 criteria moved to a new `handoff` phase (`[plan-amend:handoff-phase]`); the audit then ran 621/621.
7. **Compiled work order over 64 KB.** `compile-task.js resolve-findings` inlined the 74 KB FINDINGS.json snapshot; through a pipe the output truncates at 65536 bytes and gap-check failed with "Unexpected end of JSON input". The read-only reservation was emptied and the context points at the file.
8. **Clean-tree checks.** audit-final.8 and merge-readiness.3 counted `events.ndjson` (written by every `--start`) and the evidence files that guard runs rewrite (`evidence/gates-first.json`, `evidence/tripwire/pack-gates.json`) as dirty; they are now exempt. Running `guard.py gates-first` or `tripwire-pack` rewrites those two files, so `git restore` them after sweeps.
9. **README versus tests.** The README rewrite dropped `--allow-cdp-hosts`, `--allow-remote-listen` and the `maxResultBytes`/`omitted`/`fetch` statement that `readme-contract.spec.ts` pins; the readme-rewrite guard did not catch it, `stealth-search:test` did. Restored.
10. **Guard sweep cost.** The 74-state sweep takes about 25 minutes sequentially; `fix-tripwire.2` flakes under parallel guard load and passes alone.
11. **Standing open items (user decisions recorded).** Default port 9222 and the Chrome-CDP profile directory are final and documented; the provisional Google parsers (OD-11) stay as they are and the docs say so; no state has an unconfirmed DoD clause (every completion reported `dod_unconfirmed: []`); `dod.9` is proven after the cutover by consumer-relink, which the dispatcher runs after release. Release order: publish `@adhd/apigen-engine-runtime` 0.3.6 first, bump stealth-search to `^0.3.6`, then tripwire, core, search. Backlog and memory MCP were unreachable, so nothing was filed.
